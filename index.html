Emergent Language Sim

Agents with no shared language invent words, grammar, dialects and language families. In each round one agent sees an object and says a word; a neighbour must pick that object out of a lineup using only the word. Nobody is told any words and nobody is in charge: watch a shared vocabulary, and local dialects, appear from random babble.

    Toy languages

    Languages built by hand, with known structure, to check that every measurement means what it says before any agent invents anything. Click a row to see its dictionary.

    Topographic similarity: do similar meanings get similar words? (1 = always, 0 = no relation). Positional: does each slot of the word stand for one attribute? Bag of symbols: does each syllable stand for one attribute, wherever it goes? Information: how much of the meaning the word pins down. Ideal listener: the best any listener could do. Compositionality can't be measured with only one attribute ("n/a").
