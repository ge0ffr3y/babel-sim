Babel

Agents with no shared language invent words, grammar and dialects, and one day will build a tower with them. In each round a foreman sees the plan and calls for a piece; a builder must pick that piece out of the pile using only the word. Nobody is told any words and nobody is in charge: a shared vocabulary, and local dialects, appear from random babble. Right pieces raise the tower; wrong ones become rubble.

    The tower

    Every round the builder gets right puts the ordered piece on top (coloured by kind); every wrong piece goes on the rubble pile. The tower is only a picture of the success count: the agents can't see it.

    Generations

    At the end of each generation the foreman and builder retire. Two pupils are taught some of the old foreman's words, then must work out the rest by playing. A language that can be rebuilt from a few examples survives the handover: watch the words for related orders start to share syllables.

      Inside their heads

      Each square is one hidden unit of a tiny neural network (orange = on, blue = off). The foreman's network turns the order into a word, one syllable slot at a time; the builder's network turns the foreman's favourite word into a guess for each part. Asked without teaching them anything.

      The foreman's words, as a grid

      Rows and columns are the parts of an order; each syllable is coloured by which syllable it is. If words were built from parts (one syllable for the piece, one for the size…), you'd see stripes; one-off memorized words look like confetti. Dashed cells are never-seen orders, and a dot means no favourite word yet.

      How it's going

      Toy languages

      Languages built by hand, with known structure, to check that every measurement means what it says before any agent invents anything. Click a row to see its dictionary.

      Topographic similarity: do similar meanings get similar words? (1 = always, 0 = no relation). Positional: does each slot of the word stand for one attribute? Bag of symbols: does each syllable stand for one attribute, wherever it goes? Information: how much of the meaning the word pins down. Ideal listener: the best any listener could do. Compositionality can't be measured with only one attribute ("n/a").
